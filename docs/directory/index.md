Registry berikut sudah tertanam di dalam CLI, jadi tidak perlu konfigurasi tambahan. Untuk menambahkan komponen, jalankan: `npx kliping@latest add @<registry>/<komponen>`.

::: tip 
Registry komunitas dikelola oleh pengembang pihak ketiga. Selalu periksa kodenya saat dipasang, pastikan sesuai standar keamanan dan kualitas Anda.
:::

<RegistryDirectory />

Registry yang Anda cari belum terdaftar? Pelajari cara [menambahkannya di sini](/registry/getting-started).


## Dokumentasi

CLI `kliping` bisa Anda pakai untuk menjalankan registry kode Anda sendiri. Dengan begitu Anda bisa mendistribusikan komponen, composable, halaman, konfigurasi, aturan, dan berkas lain buatan Anda ke project mana pun.
